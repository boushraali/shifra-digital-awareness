# شفرة الوعي الرقمي — Digital Awareness Quest

منصة ويب تعليمية عربية (RTL) لطالبات المرحلتين المتوسطة والثانوية، تجمع بين:

1. **رحلة الوعي الرقمي**: لعبة مغامرة في «مدينة نوفا الرقمية» من سبعة عوالم، مع المساعدة «نور». في كل عالم قصة افتتاحية، و5 سيناريوهات بقرارات متفرعة، ولعبة مصغرة، وتقييم نهائي، ونقاط وشارة ومفتاح، وشهادة مستقلة.
2. **الدورات التدريبية (LMS)**: المعلمة تنشئ الدورات (دورة ← وحدات ← دروس ← اختبارات)، وترفع المواد، وتبني بنك أسئلة بستة أنواع. الطالبة تسجّل في الدورة، وتدرس، وتختبر، وتحصل على شهادة تلقائية.

## البنية

| الطبقة | التقنية |
|---|---|
| الواجهة | React 19، TypeScript، Tailwind CSS، Framer Motion، Recharts (في المجلد `client/`) |
| الخادم | Node.js، Express، TypeScript (`server/`) |
| قاعدة البيانات | PostgreSQL 16 (`server/db/schema.sql`) |
| الملفات | تخزين على القرص مع صلاحيات وصول (`STORAGE_DIR`) |
| المهام المجدولة | تعمل داخل الخادم كل دقيقة (`server/src/lib/jobs.ts`) |

اخترت خادم Express مع PostgreSQL بدل Supabase حتى يعمل كل شيء ويُختبر محليًا دون حساب خارجي. ما يقابل Row Level Security هنا هو أن **كل صلاحية تُفحص على الخادم في كل طلب**: الدور، وملكية المحاولة، ومواعيد المرحلة، والتسجيل في الدورة، وغيرها. المتصفح لا يحصل على أي مفتاح إجابة، ولا يرسل أي درجة.

## التشغيل المحلي

```bash
# 1) قاعدة البيانات
createdb nova            # أو استخدمي docker compose (أدناه)

# 2) الخادم
cd server
cp .env.example .env     # عدّلي DATABASE_URL و JWT_SECRET (32 حرفًا عشوائيًا على الأقل)
npm install
npm run migrate          # ينشئ الجداول ويحمّل محتوى العوالم السبعة
npm run seed:demo        # اختياري: بيانات تجريبية (تُحفظ كلمات المرور العشوائية في storage/demo-credentials.txt)
npm run dev              # http://localhost:4000

# 3) الواجهة (في نافذة أخرى)
cd client && npm install && npm run dev   # http://localhost:5173
```

إنشاء حساب معلمة فعلي (تُولَّد كلمة مرور مؤقتة قوية وتُطبع مرة واحدة، ويجب تغييرها عند أول دخول):

```bash
cd server && npm run create-teacher -- --email teacher@school.sa --name "أ. نورة" --school "اسم المدرسة"
```

## النشر على Cloudflare

راجعي [DEPLOY-CLOUDFLARE.md](DEPLOY-CLOUDFLARE.md): Worker + Container، وقاعدة البيانات PostgreSQL على Neon، والملفات على R2.

## النشر (Docker)

```bash
cp .env.example .env        # DB_PASSWORD و JWT_SECRET و PUBLIC_URL
docker compose up -d --build
docker compose exec app npm run create-teacher -- --email ... --name "..."
```

ضعي أمام الخادم وكيلًا عكسيًا يوفّر HTTPS (مثل Nginx أو Caddy)، واجعلي `PUBLIC_URL` يساوي النطاق الفعلي لأنه يُستخدم في رموز QR للشهادات. عند `NODE_ENV=production` تُرسل ملفات تعريف الارتباط بخاصية `Secure`، ويُمنع إنشاء البيانات التجريبية.

## الاختبارات

```bash
cd server && npm start &   # الخادم يعمل
npm test                   # يعيد البيانات التجريبية ثم ينفّذ 100 فحص شامل
```

تغطي الاختبارات: المصادقة وفصل الأدوار، وحماية CSRF، ومنع فتح المراحل بتغيير الرابط، والمواعيد والاستهداف والاستثناءات، وترتيب الخطوات والقرارات المتفرعة، وعدم تسريب مفاتيح الإجابات، وإصدار الشهادات دون تكرار، والتحقق العام والإلغاء، والاستيراد والتصدير، وفحص الملفات المرفوعة، والتسجيل في الدورات ومنع تكراره، والتصحيح التلقائي واليدوي، والإكمال التلقائي للدورة، والإشعارات، والتقارير، والتسليم التلقائي عند انتهاء الوقت.

## الضوابط الأمنية

- كلمات المرور مشفّرة بـ bcrypt. الحسابات الجديدة تحصل على كلمة مؤقتة تُعرض مرة واحدة ويجب تغييرها.
- الجلسة في ملف تعريف ارتباط `httpOnly` و`SameSite=Strict`، ويُتحقق منها مقابل قاعدة البيانات في كل طلب، فيسري تعطيل الحساب فورًا.
- كل طلب يغيّر البيانات يجب أن يحمل الترويسة `X-Requested-With`. يوجد حد لمحاولات الدخول، ورؤوس أمان عبر Helmet مع CSP.
- الدرجات تُحسب على الخادم فقط. مفاتيح الإجابات (`answer_key` و`questions.answer`) لا تُرسل أبدًا، والإجابات الصحيحة تظهر حسب إعداد المعلمة.
- الملفات المرفوعة يُتحقق من امتدادها ومحتواها الفعلي (magic bytes) وحجمها، ولا تُقدَّم إلا لمن يملك صلاحية الوصول إليها.
- حماية التصدير من حقن الصيغ (formula injection)، وكل استعلامات SQL مُعلَمة (parameterized).
- يُسجَّل كل إجراء إداري مهم في `audit_logs`: المواعيد، والاستثناءات، والحسابات، والشهادات، والتصحيح.
- **تقليل البيانات**: لا يُطلب رقم الهوية ولا الجوال ولا تاريخ الميلاد. البيانات التجريبية معلَّمة بـ `is_demo` ويمكن حذفها بالأمر `npm run seed:demo -- --reset`.
- **الوقت**: كل الأوقات مخزّنة بتوقيت UTC (`timestamptz`)، وتُعرض وتُدخل بتوقيت `Asia/Riyadh`.

> قبل التشغيل الفعلي راجعي متطلبات نظام حماية البيانات الشخصية (PDPL) في المملكة وسياسات الجهة التعليمية: سياسة الخصوصية، ومدة الاحتفاظ بالبيانات، وموقع الاستضافة.

## ملاحظات وقيود معروفة

- **شهادات PDF**: تُولَّد في متصفح المستخدم بدقة عالية من تصميم HTML، حتى يظهر الخط العربي وتشكيله بشكل صحيح. الملف صورة عالية الجودة داخل PDF بحجم A4 أفقي، وليس نصًا قابلًا للتحديد.
- **تقارير PDF**: تُصدَّر عبر «طباعة ← حفظ كـ PDF» في المتصفح. أما Excel وCSV فيُصدّرها الخادم مباشرة.
- **التخزين**: الملفات على القرص محليًا، وعلى Cloudflare R2 (أو أي تخزين متوافق مع S3) تلقائيًا عند ضبط `S3_BUCKET`.
- **الإشعارات**: داخل المنصة فقط، دون بريد إلكتروني أو SMS.
- **التحقق العام من الشهادة**: يعرض اسم الطالبة ونوع الشهادة وتاريخها لمن يملك رمز QR فقط، لأن الرابط يحتوي على رمز سري.

## خريطة المجلدات

```
server/
  db/schema.sql            قاعدة البيانات (25 جدولًا، مفاتيح وفهارس وقيود منع التكرار)
  src/content/worlds.ts    محتوى العوالم السبعة (قابل للتعديل ثم: npm run migrate)
  src/lib/                 المصادقة، منطق الجدولة والإتاحة، التصحيح، الشهادات، الملفات، المهام
  src/routes/              واجهات API للطالبة (journey, learn) وللمعلمة (teacher/*)
  tests/e2e.ts             الاختبارات الشاملة
client/src/
  pages/student/           تجربة الطالبة (خريطة الرحلة، محرك اللعبة، الدورات، الشهادات)
  pages/teacher/           لوحة المعلمة (11 قسمًا)
  components/              الهوية البصرية، الشهادة، الإشعارات
```
